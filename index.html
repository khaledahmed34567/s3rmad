Everyday developer tools that run entirely in your browser. Nothing you paste or type is ever sent anywhere.

JSON formatter and validator

Paste JSON to validate it, pretty-print it, or minify it. Errors show the line and column.

Paste JSON to get started.

JWT decoder

Reads the header, payload and signature of a JSON Web Token. The signature is not verified.

Paste a token to decode it.

Hash generator

Computes SHA-256 and SHA-512 with your browser’s built-in Web Crypto. Hash text as you type, or choose a file.
